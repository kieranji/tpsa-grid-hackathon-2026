# tpsa-grid-hackathon-2026
TPSA Hackathon 2026 - Efficiency in Ireland's Electrical Grid

## Evidence-based BESS economics (10 September 2026)

The new `src/bess_market` workflow separates the synthetic 2033 network planning
case from observed SEMOpx price backtests. It jointly schedules energy trading,
a conditional reserve block and conservative capacity availability, with one
SOC/power/cash ledger. It does **not** count avoided curtailment or system-cost
savings as additional developer cash. No future service or capacity contract is
assumed secured.

```sh
pip install -r requirements-bess-market.txt
PYTHONPATH=src python -m bess_market.pipeline --datasets 2023 recent 2019 2020 2021
python scripts/bess_duration_sensitivity.py
python -m pytest tests -q
python scripts/test_market_data.py
```

In PowerShell set `$env:PYTHONPATH='src'` before the module command. The committed
normalized input snapshot requires no download to reproduce. Source URLs,
timestamps, coverage and file hashes are in `data/market/`. Optional refresh:
`python scripts/fetch_semopx_prices.py` and `python scripts/fetch_cso_cpi.py`.

Git tracks the source, observed inputs, annual cashflows and compact result
summaries. Detailed interval `dispatch_*.csv.gz` files are generated by the run
and included in the separately supplied full study archive.

All investment outputs use constant 2024 EUR, a 15-year maintained-capacity cost
benchmark and an assumed 7% real discount rate. The causal strategy uses only old
prices; the daily oracle is a hindsight cash upper benchmark under the model's
constraints. Neither proves a future 2033 return, market execution, site access
or N-1 security. The 363-day recent input is labelled and annualized explicitly;
missing prices are never filled. One-year contracts expire in the cash ledger;
15-year repeated awards are a separate, clearly conditional sensitivity.

The corrected 168-hour network replay reproduces the all-island internal flows.
The original Q2 recovery benchmark is not equivalent to constraint elimination:
the candidate must also pass the same-BESS target-relaxed residual test.
